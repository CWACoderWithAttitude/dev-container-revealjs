The Problem

LLMs - LargeLanguageModels - are more or less limited to the data they were trained on.

  • They can’t access up-to-date information

  • They can’t perform actions on external systems

  • They can’t utilize specialized tools or services

    --- LLMs können nur auf die Daten zugreifen, mit denen sie trainiert wurden ---

Ohne MCP

  • Each Integration requires custom code.

  • No standardization

  • Hard to maintain

  • Difficult to scale

Stellen Sie sich vor, Sie müssten für jede App auf Ihrem Smartphone eine eigene Sprache lernen

Solution:

Model Context Protocol (MCP)

What’s MCP?

  • MCP Servers add access to resources like files, databases, APIs, and tools.

  • They communicate with LLMs using a standardized protocol.

  • MCP enables LLMs to perform actions and access up-to-date information.

How does it work?

MCP Workflow

  1. User interacts with ChatBot (e.g., Claude)

  2. Traing data enables the AI to "understand" the User

  3. Claude sends request to MCP 3.1 Based on thr User context the AI decides which MCP Server to call 3.2 MCP Server uses its capabilities to access external resources 3.3 MCP Server return data to Claude 3.4 Claude generates response for User

✨ Result: The User gets up-to-date information and actions performed by the AI!

How are MCP Servers connected?

  • Standard communication is via STDIO - local only

  • More modern approaches use HTTP/HTTPS - network & streaming

  • Previously SSE (Server-Sent Events) - now WebSockets

  • Future possibilities include gRPC and other protocols

MCP Server entwickeln

Technologie-Stack

  • Python - Am weitesten verbreitet

  • TypeScript/Node.js - Für Web-Entwickler

  • Andere Sprachen - SDK in Entwicklung

Einfaches Beispiel (Python)

from mcp.server import Server
from mcp.types import Tool

server = Server("mein-server")

@server.tool()
async def berechne_summe(a: int, b: int) -> int:
    """Addiert zwei Zahlen"""
    return a + b

# Server starten
server.run()

So einfach kann ein MCP Server sein - nur wenige Zeilen Code

Was macht dieser Code?

  1. Importiert MCP Bibliotheken

  2. Erstellt einen Server

  3. Definiert ein Tool (Funktion)

  4. Startet den Server

✨ Ergebnis: Claude kann jetzt Zahlen addieren!
