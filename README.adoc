= Containerized ASCIIDoctor Presentations

== TL;DR
DevContainer for crating presentation with Asciidoctor and RevealJS.

== Requirements
Just docker desktop or similar framework to run devcontainers. 
All the rest should be covered by this setup.

== What
DevContainer implements the PaC pattern. Presentation As Code.
Build beautiful presentations with AsciiDoc and RevealJS.

== Contents
* Based on a node image
* Includes a fs watcher. A full rebuild is triggered once a change to a `.adoc` file is detected.
* Include Five-Server for live preview

== Why
I creating presentations to be easy and platform agnostic.
Since i'm lazy as hell i created this setup.
