=== Hammer: Beispiel: Abfrage von Versicherungs-Produkten

Die Abfrage fand über den Playwrigth MCP Server statt.

Durch diesen kann eine automatiosche Websuche durchgeführt werden.

Meine Frage:
```
Bitte gehe zur Helvetia-Homepage.
Suche Produkte für Privatkunden.  
Nenne mir Produkte für PV--Anlagen und Wärmepumpen.
```

https://claude.ai/share/bcddbbba-a919-427f-a287-8fb9b577cdc4[Die Antwort]

=== Ober-Hammer: Noch genauer

```
Bitte gehe zur deutschen Helvetia-Homepage.
Akzeptiere alle Cookies.
Suche Produkte für Privatkunden.
Nenne mir Produkte für PV--Anlagen und Wärmepumpen.
Mache von allen gefundenen Produkten Screenshots.
```
