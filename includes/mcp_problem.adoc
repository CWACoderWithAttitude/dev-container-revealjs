== The Problem

LLMs like Claude, Mistral, ChatGPT... are powerfull tools.

But there are boundries:
- They are limited to their training data
- `Grounding` is no real solution for business problems.
- They have no built-in access to external data or tools.
// Integrating them with various services requires custom code for each service, leading to high maintenance and scalability issues.

=== Ohne MCP

* No standardization
* Hard to maintain
* Difficult to scale
