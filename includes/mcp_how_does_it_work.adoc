== Wie funktioniert MCP?

=== How does it work?

image::images/mcp-server-env.png[MCP Server Environment Logo]

[.step]
1. Claude sends request to MCP
2. MCP Server translates and calls API
3. Response is returned to Claude

=== How are MCP Servers connected?

[.step]
* Standard communication is via STDIO - local only
* More modern approaches use HTTP/HTTPS - network & streaming
* Previously SSE (Server-Sent Events) - now WebSockets
* Future possibilities include gRPC and other protocols
