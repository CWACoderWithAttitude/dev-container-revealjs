== Architecture in Detail

=== MCP Server Structure

[source,text]
----
MCP Server
├── Resources
│   └── Provide data
├── Tools
│   └── Aktionen ausführen
├── Prompts
│   └── Vorlagen anbieten
└── Transport
    └── Kommunikation
----

=== Resources (Ressourcen)

*Was sind Resources?*

Daten, die der Server bereitstellt

[.step]
* Dateien
* Datenbankeinträge
* API-Antworten
* Statische Inhalte

=== Tools (Werkzeuge)

*Was sind Tools?*

Aktionen, die der Server ausführen kann

[.step]
* `create_file()` - Datei erstellen
* `search_database()` - Datenbank durchsuchen
* `send_email()` - E-Mail versenden
* `calculate()` - Berechnung durchführen

=== Prompts (Vorlagen)

*Was sind Prompts?*

Vordefinierte Gesprächsvorlagen

[.step]
* Standardabfragen
* Best Practices
* Häufige Workflows
* Kontextuelle Hilfe

[.step]

[.fragment]
⏱️ *Zeit:* 2-3 Minuten

== MCP Server entwickeln

=== Technologie-Stack

[.step]
* *Python* - Am weitesten verbreitet
* *TypeScript/Node.js* - Für Web-Entwickler
* *Andere Sprachen* - SDK in Entwicklung

=== Einfaches Beispiel (Python)

[source,python]
----
from mcp.server import Server
from mcp.types import Tool

server = Server("mein-server")

@server.tool()
async def berechne_summe(a: int, b: int) -> int:
    """Addiert zwei Zahlen"""
    return a + b

# Server starten
server.run()
----

[.notes]
--
So einfach kann ein MCP Server sein - nur wenige Zeilen Code
--

=== Was macht dieser Code?

[.step]
1. Importiert MCP Bibliotheken
2. Erstellt einen Server
3. Definiert ein Tool (Funktion)
4. Startet den Server

[.fragment]
✨ *Ergebnis:* Claude kann jetzt Zahlen addieren!
